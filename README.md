# HIMALAYAN ZAIKA

Production-ready static frontend for `himalayanzaika.in` connected to the project's Supabase backend.

## Features
- Responsive hotel discovery and booking
- Live room availability checks
- Authenticated customer accounts
- My Bookings
- Tours & Packages with dedicated tour requests
- Taxi requests
- Admin dashboard with hotel/room/tour editing and request management
- Homepage wallpaper upload via Supabase Storage
- Booking confirmation/cancellation notifications through Supabase Edge Function

## Deployment
Point `himalayanzaika.in` to the production hosting deployment. The frontend uses the Supabase publishable key; no service-role secret is bundled.
